# UAAP compiled archive

Generated by `npx tsx scripts/compile-uaap-archive-master.ts`.

## Open these

| File | What it is |
| --- | --- |
| `UAAP_Complete_Digital_Book.html` | All 7 season annual reports in one searchable book (use this to read). |
| `UAAP_Complete_Digital_Book.md` | Same book as Markdown. |
| `UAAP_Admin_Paste_Pack.md` | Every division as a copy-paste table for Admin → UAAP Archive → Bulk import. |
| `uaap_standings_master.xlsx` | Excel masterfile: `Master` sheet, `Coverage` sheet, plus one sheet per sport. |
| `uaap_standings_master.csv` | Same rows as the Excel Master sheet. |
| `paste/YYYY-YYYY/*.txt` | One file per season / sport / division if you prefer copying from Explorer. |

## How to paste into admin

1. Open Admin → UAAP Archive.
2. Set Season, Sport, and Division to match the heading.
3. Copy the table **including the header row**.
4. Bulk import → Parse → Apply to editor → Save.

OCR yearbooks still contain typos. Check a row or two against the digital book before saving.
